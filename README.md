# Афиша Studio

Пакетная замена афиш на фотографиях через xAI Images Edit API.

## Запуск

Node.js 22.13+; `npm install`, затем `npm run dev -- --hostname 127.0.0.1`.
Приложение использует Sites / Cloudflare Workers и R2 (`BUCKET`). Локальное R2 создаётся автоматически в `.wrangler`.

## Работа

1. Загрузите JPG, PNG или WebP: до 500 фотографий и 50 новых макетов, до 10 МБ на файл.
2. Выберите Grok Imagine Image 2.0 или Grok Imagine Image, инструкцию и распределение: равномерное случайное, независимое случайное или последовательное.
3. Создайте очередь. На каждую фотографию назначается один макет, применяемый ко всем указанным афишам в кадре.
4. Введите собственный API-ключ xAI. Выполните пробу на одной фотографии, проверьте результат, затем запустите оставшуюся очередь.
5. Скачайте ZIP с готовыми изображениями и `report.json`. Неуспешные задания остаются в отчёте. Кнопка «Начать новую серию» очищает текущую серию после подтверждения.

Файлы и очередь сохраняются в R2 под случайным идентификатором браузера в HttpOnly cookie. Очистка cookies или другой браузер не восстанавливают прежнюю серию. Ключ не сохраняется в R2, cookies или localStorage и передаётся только серверу приложения и xAI. Доступ к опубликованному сайту — только владельцу через Sites.

Очередь выполняется последовательно при открытой вкладке. Пауза завершает текущий запрос. После перезагрузки можно продолжить оставшиеся задания. Автоматических платных повторов нет; незавершённый запрос можно вернуть в очередь через 10 минут. Обработка может быть оплачена даже при обрыве соединения. Настройки фиксируются при создании очереди.

## Ограничения и проверка

Это генеративное редактирование, а не точное пиксельное наложение: буквальное сохранение шрифтов, текста, окружения и размеров изображения не гарантируется. На сложных тумбах сначала нужна проба. Ручные маски и независимое назначение нескольких макетов внутри одного кадра не реализованы. Фоновое выполнение при закрытом браузере не реализовано.

`node --test tests/core.test.mjs` проверяет распределение и ZIP. `node tests/api.mjs` при запущенном локальном сервере проверяет загрузки, очередь, изоляцию, валидацию и очистку на отдельной тестовой сессии. `node node_modules/typescript/bin/tsc --noEmit` и `npm run build` проверяют типы и сборку.

Реальное редактирование через xAI не тестировалось без ключа и пользовательских фотографий. Реализация следует https://docs.x.ai/developers/model-capabilities/images/multi-image-editing и использует POST https://api.x.ai/v1/images/edits с двумя упорядоченными изображениями.
