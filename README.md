# Афиша Studio / pictures_insert

Самостоятельное веб-приложение для пакетной замены афиш на фотографиях через API xAI (Grok). Можно развернуть на собственном Linux-сервере, в Docker или запустить на Windows/macOS с Node.js.

**Для обычного запуска не нужны Sites, Cloudflare, аккаунт OpenAI, внешняя база данных или отдельный Redis.** Интерфейс собирается Vite, сервер использует встроенные модули Node.js, файлы и очередь сохраняются в локальной SQLite. Для реального редактирования необходимы интернет, API-ключ xAI и средства на счёте xAI.

## Возможности

- До 500 фотографий и 50 новых макетов в серии; JPG, PNG, WebP, до 10 МБ на файл.
- Grok Imagine Image 2.0 / Grok Imagine Image; текстовая инструкция замены.
- Случайное равномерное, независимое случайное или последовательное распределение.
- От 1 до 4 параллельных запросов, по умолчанию 2; снижение параллельности для крупных файлов.
- Проба на одном фото, пауза, ручной повтор ошибки, сохранение результатов, сравнение до/после.
- ZIP с готовыми изображениями и отчётом `report.json`.
- Пароль для доступа к собственному серверу; отдельная серия для каждого браузера.

## Быстрый запуск без Docker

Нужен **Node.js 24.12+** (рекомендуется актуальный Node.js 24 LTS).

```bash
git clone https://github.com/rdv77/pictures_insert.git
cd pictures_insert
npm ci
cp .env.example .env
npm run build
npm start
```

Открыть http://localhost:3000. В PowerShell вместо `cp` можно использовать `Copy-Item .env.example .env`. По умолчанию сервер слушает только `127.0.0.1`, данные находятся в `./data/afisha.sqlite`.

Для разработки: `npm run dev` (интерфейс с горячим обновлением и API на одном порту). Сборка не нужна перед dev-запуском.

## Docker

```bash
cp .env.example .env
# Установите APP_PASSWORD длиной от 16 символов в .env.
docker compose up -d --build
```

Открыть http://localhost:3000. Браузер попросит логин и пароль: логин любой (например, `admin`), пароль — значение `APP_PASSWORD`. Compose откажется запускаться с пустым паролем. Контейнер хранит данные в постоянном томе `afisha-data`. Не запускайте `docker compose down -v`, если хотите сохранить данные.

**Подробная установка на VPS, HTTPS, резервные копии и обновление:** [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Тесты включают SQLite, конкурентное изменение заданий, очередь на 100 заданий, HTTP-авторизацию, загрузки, обработку через имитацию xAI, ZIP и восстановление после перезапуска. Тесты не отправляют платных запросов и не требуют API-ключа. GitHub Actions также собирает Docker-образ.

## Важные границы

Автономность означает **независимое развёртывание**, а не офлайн-генерацию. Очередь отправляется из открытой вкладки: после её закрытия новые задания не отправляются. Уже принятый Node.js-сервером запрос может завершиться и сохраниться. Для продолжения откройте тот же браузер, снова введите ключ и запустите очередь.

Генеративное редактирование может изменить мелкий текст, шрифты, детали сцены и размеры изображения. Это не точное пиксельное наложение. Сначала проверьте один результат. Один новый макет назначается всей фотографии; разные макеты на нескольких поверхностях одного кадра и ручные маски пока не поддерживаются.

Ранее опубликованный вариант Sites поддерживается отдельными командами `npm run dev:sites` и `npm run build:sites`. Самостоятельный сервер эти сервисы не использует; его данные не переносятся автоматически из Sites. Текущий сайт не требуется изменять для развёртывания копии на своём сервере.
