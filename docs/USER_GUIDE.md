# Работа с приложением

## 1. Вход и загрузка

Откройте адрес установки. Если браузер просит логин и пароль: логин любой, например admin; пароль — APP_PASSWORD администратора. На localhost без заданного пароля диалога нет.

В «Фотографии» загрузите снимки, в «Новые афиши» — сами макеты. Можно перетаскивать сразу множество файлов. Лимиты: 500 фотографий, 50 макетов, JPG/PNG/WebP до 10 МБ. Загрузка в хранилище последовательная, генерация запускается отдельно. Крестик удаляет файл до создания очереди; используемый в заданиях файл защищён.

## 2. Настройки

| Настройка | Поведение |
|---|---|
| Модель | Grok Imagine Image 2.0 / Grok Imagine Image; доступ зависит от xAI |
| Случайно, поровну | 100 фото и 2 макета: ровно 50 назначений каждого в перемешанном порядке |
| Полностью случайно | Независимый выбор, равные количества не гарантированы |
| По очереди | Макеты чередуются в порядке загрузки |
| Одновременные запросы | 1–4, рекомендуется начать с 2; крупные файлы уменьшают число |
| Что заменить | Указание нужных поверхностей и деталей для сохранения |

Пример инструкции: «Заменить только большую центральную афишу на тумбе. Сохранить окружающие объявления, ракурс, тени и людей».

На всю фотографию назначается один новый макет. Разные макеты на отдельных поверхностях внутри одного кадра и ручные маски пока не поддерживаются.

## 3. Создание очереди и проба

Нажмите «Создать очередь», проверьте назначенные пары до оплаты. Модель, инструкция и распределение фиксируются для серии. Полностью изменить их можно через новую серию; сначала сохраните нужные результаты.

Создайте ключ в https://console.x.ai и убедитесь в доступе к API и средствах. Вставьте ключ в интерфейсе. Он не сохраняется при закрытии/перезагрузке. Подписка на чат Grok сама по себе не заменяет настройку API.

Нажмите «Проба на 1 фотографии». Проверяется первое ожидающее задание. Сравните текст, логотипы, форму тумбы, перспективу, тени и окружение. Оплата идёт со счёта xAI.

## 4. Серия и пауза

«Запустить всю серию» / «Продолжить обработку» отправляет оставшиеся задания. Готовая проба не вызывается повторно. Держите вкладку открытой. Порядок завершения может отличаться от порядка фото, назначения макетов сохраняются.

Пауза прекращает новые отправки, но уже принятые запросы завершаются и могут быть оплачены. Первая ошибка тоже останавливает новые запросы. Увеличение параллельности не уменьшает количество платных изображений и не ускоряет отдельную генерацию.

## 5. ZIP и новая серия

«Скачать ZIP» включает все done, даже если остальная серия не закончена. Имена состоят из порядкового префикса и исходного имени; расширение соответствует результату. report.json содержит все назначения, статусы и ошибки. Оригиналы не включаются.

Сервер формирует архив потоком, но браузер получает Blob перед скачиванием. Очень большие архивы требуют памяти браузера. ZIP ограничен 4 ГБ — делите крупные серии заранее.

«Начать новую серию» после подтверждения удаляет текущие файлы, задания и результаты. Сначала скачайте нужное.

## Восстановление

| Ситуация | Что делать |
|---|---|
| Ключ отклонён | Проверить ключ и доступ к модели, вернуть ошибку в очередь |
| 429 / средства | Проверить баланс/лимиты, уменьшить параллельность, повторить позже |
| Обрыв | Обновить состояние; оплата могла произойти, автоматического повтора нет |
| Зависло running | Подождать 10 минут с запуска, обновить; при необходимости вернуть вручную |
| Пусто после рестарта | Проверить прежние cookies и DATA_DIR/том сервера |
| POST возвращает 403 | Проверить APP_ORIGIN: протокол, домен и порт должны совпадать с браузером |

После смены браузера или удаления cookies будет новая серия. Общий пароль не позволяет найти старую серию. Перед сменой устройства выгрузите результаты.
